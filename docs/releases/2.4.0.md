# Release 2.4.0 — Google Business Profile draft (English)

**4WP SEO Helper** — site-wide SEO Inventory, Google Search Console, Trends, and SERP Positions in wp-admin (P1–P3 lanes, Yoast/AIOSEO, REST sync, URL inspection, indexing). Optional AI copy via the standard WordPress AI Client (Settings → Connectors).

## Version 2.4.0

**Positions** tracks Google rank for each query + country through Serper. The Search Console property is the domain we look for. Each Update stores a dated organic snapshot. Hover SERP titles; Ask / Suggest shows People also ask and related searches (unique phrases keep every source query ID).
