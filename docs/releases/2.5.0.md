# 4WP SEO Helper 2.5.0

**Published:** 2026-10-09  
**WordPress.org:** https://wordpress.org/plugins/4wp-seo-helper/

## Summary

**Cross posting** for packages imported from **4WP Drive** (`meta.json`): manage platforms, delay after the original is published, Telegram share list, manual send from the editor, and a publication log (live URL/slug) from the Chrome extension / REST.

## Highlights

- **Settings** — Cross posting module toggle; default delay in hours (optional minutes).
- **4WP SEO → Platforms** — taxonomy of share targets (Dev.to, daily.dev, Hashnode, Medium, X, custom).
- **Editor sidebar** — load status per platform, manual send, Telegram notify for the share list.
- **Schedule** — WP-Cron after the WordPress post is published; per-package republish delay from `meta.json` when set.
- **REST** — `/crosspost`, `/crosspost/notify`, `/crosspost/published`, `/crosspost/payload`, `/crosspost/board`.
- **Cross posting board** + Material admin screen for the workflow.
- **Publication record** on the post (`_forwp_seo_crosspost_log`); Chrome extension records live slug/URL.
- **4WP Drive** — TechArticle Steps wrap supports contiguous Step H2 sections (`span: multi`).
