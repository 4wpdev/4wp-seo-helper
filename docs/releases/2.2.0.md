# Release 2.2.0 — Google Business Profile draft (English)

**4WP SEO Helper** — site-wide SEO Inventory and Google Search Console in wp-admin (P1–P3 lanes, Yoast/AIOSEO, REST sync, URL inspection, indexing). Optional AI copy via the standard WordPress AI Client (Settings → Connectors).

## Version 2.2.0

AI Assistant generates SEO title, meta description, and focus keyphrases through **WordPress AI Client / Connectors** — no custom vendor SDK. Inventory Generate defaults to page content. Dashboard widgets stay configurable (Screen Options, drag/hide) with 7 / 28 / 90 day Search Console ranges. Dynamics lists what changed (search clicks/impressions, content, score). Inventory CSV export sits on the tabs row.
