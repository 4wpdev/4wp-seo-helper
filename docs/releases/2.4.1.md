# 4WP SEO Helper 2.4.1

**Published:** 2026-09-20
**WordPress.org:** https://wordpress.org/plugins/4wp-seo-helper/

## Summary

4WP SEO Helper now registers TechArticle section wraps with **4WP Drive**, so imported Goal / Context / Steps / Common mistakes headings can become Gutenberg wrappers.

## Highlights

- Drive Patterns → Integrations Plugins shows **4WP SEO Helper** when this plugin is active.
- Map: `tech-article` (or TechArticle) in front-matter, heading aliases in Patterns, or wrap pin in Incoming.
- [4WP Drive on WordPress.org](https://wordpress.org/plugins/4wp-drive/).
