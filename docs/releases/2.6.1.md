# 4WP SEO Helper 2.6.1

**Published:** 2026-10-26  
**WordPress.org:** https://wordpress.org/plugins/4wp-seo-helper/

## Summary

AI agents can read a page body to write content and SEO meta from it, with admin-controlled size. Yoast SEO now shows SEO meta written by abilities and bulk updates.

## Highlights

- **`forwp-seo-helper/get-content`** (read-only): post_content by ID or slug.
  - Formats: `text` (cleaned, default, cheapest), `html` (blocks + shortcodes rendered), `blocks` (raw).
  - Extras: heading outline, word count, internal / external links, images without alt, current SEO meta.
  - `source: "post_content"` and a `notice` in every response: the public page may include more (theme template, header/footer, sidebars, template parts, plugin output).
  - Permissions: `read_post`; drafts and password-protected posts need `edit_post`.
- **Settings → AI agents (Abilities): page content** — allowed formats (default: text only), default format, max characters (default 20 000).
- **Fix (Yoast SEO):** after a meta write the existing indexable is rebuilt through Yoast's post watcher (previously abilities did not refresh it, and Inventory quick edit created a new indexable row on every save). Yoast persists indexables only in production mode.
- **Fix:** abilities resolve child pages by plain slug or full path.

Why `text` by default — measured on one page: page HTML by URL ~140 000 tokens, cleaned page text ~330, post_content text ~130.
