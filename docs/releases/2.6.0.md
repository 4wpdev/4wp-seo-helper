# 4WP SEO Helper 2.6.0

**Published:** 2026-10-26  
**WordPress.org:** https://wordpress.org/plugins/4wp-seo-helper/

## Summary

**Abilities API** support (WordPress 6.9+): AI agents audit, search, and edit SEO meta. With **4WP MCP Connector** and the official **MCP Adapter**, an administrator manages SEO meta from Claude Desktop.

## Highlights

- Category `forwp-seo-helper`, four abilities:
  - `list-missing-meta` — no SEO title and description (`none`), one missing (`incomplete`), or any (`any`); shows the SEO plugin template value.
  - `get-meta` — raw (manual) and effective (after templates) SEO meta by ID or slug.
  - `update-meta` — SEO title, meta description, focus keyword by ID or slug; saved through the active adapter (Yoast SEO / AIOSEO); returns `before` / `after`; recorded in SEO history.
  - `search` — by title / slug or focus keyword.
- Registered only when the Abilities API exists and SEO Inventory is enabled; WordPress 6.0–6.8 unaffected.
- Reference: `docs/ABILITIES.md`.
